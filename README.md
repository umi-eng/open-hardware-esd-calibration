# Open Hardware ESD Calibration

Open-source designs for calibrating and characterising ESD simulators.

## Safety

This repository contains hardware designs for calibrating and characterising ESD
simluators. These designs involve circuits that generate, measure, or are
exposed to high-votlage transients and are intended for use only be qualified
personel with appropriate training in eletrical safety and ESD/EMC test
practices.
